# SPICE Make Project File Command (link_include_remote)

> **Last Edit: 2026-09-13**

## Overview

This document was descript the command `link_include_remote`.

This command is used by include the dependence from remote repository.

## Use

```cmake
link_include_remote([Author] [Module] [Version])
```

- `Author`: Module author.
- `Module`: Module name.
- `Version`: Module version.

This command will automatically search for module from the remote repository lists.
