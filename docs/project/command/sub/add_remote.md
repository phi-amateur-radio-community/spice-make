# SPICE Make Project File Command (add_remote)

> **Last Edit: 2026-09-13**

## Overview

This document was descript the command `add_remote`

This command is used by include the remote repository for Spice Make.

## Use

```cmake
add_remote([Repository Name] [Repository URL])
```

- `Repository Name`: The name of remote repository which was included.
- `Repository URL`: The URL of remote repository which was included.
