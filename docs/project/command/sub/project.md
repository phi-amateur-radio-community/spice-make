# SPICE Make Project File Command (project)

> **Last Edit: 2026-09-13**

## Overview

This document was descript the command `project`.

This command is used by descript the project information.

## Use

```cmake
project([Project Name] [Project Version])
```

- `Project Name`: The name of the project.
- `Project Version`: The version of the project.
