# SPICE Make Project File Command (expend_library)

> **Last Edit: 2026-09-13**

## Overview

This document was descript the command `expend_library`

This command is used by include the module to the library.

## Use

```cmake
expend_library([Library Name] [Module Name])
```

- `Library Name`: The name of the library which include for.
- `Module Name`: The name of the module which was included.
