# SPICE Make Project File Command (add_library)

> **Last Edit: 2026-09-13**

## Overview

This document was descript the command `add_library`

This command is used by create a new library for Spice Make.

## Use

```cmake
add_library([Library Name])
```

- `Library Name`: Name of library which was created.
