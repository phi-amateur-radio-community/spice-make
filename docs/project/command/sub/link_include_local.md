# SPICE Make Project File Command (link_include_local)

> **Last Edit: 2026-09-13**

## Overview

This document was descript the command `link_include_local`.

This command is used by include the dependence from local library.

## Use

```cmake
link_include_local([Library Path])
```

- `Library Path`: The path of the local library which will be included.
