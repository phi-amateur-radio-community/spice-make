# SPICE Make Project File Command (smake)

> **Last Edit: 2026-09-13**

## Overview

This document was descript the command `smake`.

This command is used by descript the project information that about Spice Make.

## Use

```cmake
smake([Spice Make Version])
```

- `Spice Make Version`: The version of the Spice Make that this project was used.
