# SPICE Make Project File Command (add_simulate)

> **Last Edit: 2026-09-13**

## Overview

This document was descript the command `add_simulate`.

This command is used by create the simulating task.

## Use

```cmake
add_simulate([Simulate Name] [Main File Path])
```

- `Simulate Name`: The name of the simulate task.
- `Main File Path`: The simulate entry point of Spice Make.
