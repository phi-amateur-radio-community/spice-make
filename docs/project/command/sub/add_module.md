# SPICE Make Project File Command (add_module)

> **Last Edit: 2026-09-13**

## Overview

This document was descript the command `add_module`

This command is used by create a new module of the library for Spice Make.

## Use

```cmake
add_module([Name] [Version] [File Path]...)
```

- `Name`: The name of the module which was created.
- `Version`: The version number of the module.
- `File Path`: The paths of several source code files which was included in this module.
